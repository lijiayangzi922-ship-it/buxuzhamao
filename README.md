# 不许奓毛

一款暖白手账风格的肩背训练与记录工具。支持动作示意、跟练计时、组间休息、训练日历与周期计划，使用原创蜡笔小毛驴作为品牌角色。

这是无需构建的静态 PWA，可由 GitHub Pages 直接托管此目录。使用 HTTPS 打开后，可在支持的浏览器中添加到主屏幕；已缓存的核心资源可离线使用。真人动作视频通过链接打开第三方原站，需要联网。

训练记录、偏好及文案轮换顺序保存在当前浏览器的本地存储中，不会自动上传。不同浏览器或站点地址不共享记录，可在“我的”页面导出和导入数据。本仓库不包含个人训练记录。

本工具用于训练辅助与记录，不提供医学诊断，也不承诺固定周期内达到矫正效果。请按个人情况及专业建议调整训练。

中文使用[小赖字体 Xiaolai](https://github.com/lxgw/kose-font)，以 SIL Open Font License 1.1 分发，许可证全文位于 [assets/fonts/OFL-Xiaolai.txt](assets/fonts/OFL-Xiaolai.txt)。英文字体通过 Google Fonts 加载，并提供系统字体回退。
